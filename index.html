Unidad 1: Repositorios y Listas en Java

Concepto

Un Repositorio es una clase encargada de gestionar una colección de objetos (como una base de datos en memoria). Utiliza estructuras de datos de Java como ArrayList para permitir operaciones fundamentales: Guardar (Insertar), Listar (Consultar), Buscar y Eliminar objetos de una clase específica.

Ejemplo práctico en Java

import java.util.ArrayList;
import java.util.List;

class Producto {
    String nombre;
    double precio;
    public Producto(String nombre, double precio) {
        this.nombre = nombre; this.precio = precio;
    }
}

public class ProductoRepositorio {
    private List<Producto> lista = new ArrayList<>();

    public void guardar(Producto p) {
        lista.add(p);
        System.out.println("Producto guardado: " + p.nombre);
    }

    public void listar() {
        for (Producto p : lista) {
            System.out.println("- " + p.nombre + " ($" + p.precio + ")");
        }
    }
}

Ejercicio Práctico

Crea una clase Estudiante con atributos String nombre y int cedula. Luego, crea un repositorio llamado EstudianteRepositorio que contenga un ArrayList<Estudiante> y métodos para guardar(Estudiante e) y listarEstudiantes().

Solución sugerida:

import java.util.ArrayList;
import java.util.List;

class Estudiante {
    String nombre;
    int cedula;
    public Estudiante(String nombre, int cedula) {
        this.nombre = nombre;
        this.cedula = cedula;
    }
}

public class EstudianteRepositorio {
    private List<Estudiante> repositorio = new ArrayList<>();

    public void guardar(Estudiante e) {
        repositorio.add(e);
        System.out.println("Estudiante guardado: " + e.nombre);
    }

    public void listarEstudiantes() {
        for (Estudiante e : repositorio) {
            System.out.println("Cédula: " + e.cedula + " | Nombre: " + e.nombre);
        }
    }
}

Unidad 2: Interfaces Gráficas con Java Swing (JFrame)

Concepto

Java Swing es la librería gráfica estándar para construir aplicaciones de escritorio. Un JFrame representa la ventana principal de la aplicación. Sobre ella se pueden añadir componentes útiles como JLabel (textos), JTextField (campos de texto), JButton (botones) y JTextArea para mostrar información.

Ejemplo práctico en Java

import javax.swing.*;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

public class VentanaEjemplo extends JFrame {
    public VentanaEjemplo() {
        setTitle("Mi Ventana Swing");
        setSize(300, 200);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLayout(null);

        JLabel lbl = new JLabel("Escribe algo:");
        lbl.setBounds(20, 20, 100, 25);
        add(lbl);

        JTextField txt = new JTextField();
        txt.setBounds(20, 50, 200, 25);
        add(txt);

        JButton btn = new JButton("Saludar");
        btn.setBounds(20, 90, 100, 30);
        add(btn);

        btn.addActionListener(new ActionListener() {
            public void actionPerformed(ActionEvent e) {
                JOptionPane.showMessageDialog(null, "Hola, " + txt.getText());
            }
        });
    }

    public static void main(String[] args) {
        new VentanaEjemplo().setVisible(true);
    }
}

Ejercicio Práctico

Crea un JFrame que contenga un JTextField para ingresar un número, un JButton con el texto "Doble" y un JLabel de resultado. Al hacer clic en el botón, el programa debe calcular el doble del número ingresado y mostrarlo en el label.

Solución sugerida:

import javax.swing.*;

public class VentanaDoble extends JFrame {
    public VentanaDoble() {
        setTitle("Calcular Doble");
        setSize(250, 200);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLayout(null);

        JTextField txtNumero = new JTextField();
        txtNumero.setBounds(30, 30, 160, 25);
        add(txtNumero);

        JButton btnCalcular = new JButton("Doble");
        btnCalcular.setBounds(30, 70, 100, 30);
        add(btnCalcular);

        JLabel lblResultado = new JLabel("Resultado: ");
        lblResultado.setBounds(30, 110, 180, 25);
        add(lblResultado);

        btnCalcular.addActionListener(e -> {
            try {
                int num = Integer.parseInt(txtNumero.getText());
                int doble = num * 2;
                lblResultado.setText("Resultado: " + doble);
            } catch (NumberFormatException ex) {
                JOptionPane.showMessageDialog(null, "Ingrese un número válido.");
            }
        });
    }

    public static void main(String[] args) {
        new VentanaDoble().setVisible(true);
    }
}

Unidad 3: Patrón de Arquitectura MVC (Modelo - Vista - Controlador)

Concepto

El patrón MVC separa las responsabilidades de una aplicación en tres partes:
- Modelo (Model): Contiene los datos y la lógica de negocio (clases y repositorios).
- Vista (View): La interfaz gráfica de usuario (componentes Swing y JFrame).
- Controlador (Controller): El intermediario que escucha a la Vista, actualiza el Modelo y refresca la pantalla.

Ejemplo conceptual de integración MVC

class TareaModelo {
    private String descripcion;
    public void setDescripcion(String d) { this.descripcion = d; }
    public String getDescripcion() { return descripcion; }
}

class TareaControlador {
    private TareaModelo modelo;
    public TareaControlador(TareaModelo modelo) {
        this.modelo = modelo;
    }
    public void actualizarTarea(String texto) {
        modelo.setDescripcion(texto);
    }
}

Ejercicio Práctico

Explica con tus palabras cómo interactúan la Vista (un botón en Swing) y el Controlador cuando un usuario registra un nuevo elemento en el sistema.

Solución sugerida:

Flujo paso a paso:
1. El usuario escribe los datos en la Vista y hace clic en el botón.
2. El botón avisa al Controlador a través de un evento.
3. El Controlador procesa la información y se la envía al Modelo (Repositorio) para que la guarde en la lista.
4. El Controlador actualiza la Vista para reflejar los cambios.

Unidad 4: Proyecto Integrado

Concepto

Unimos todo lo aprendido: una clase de datos, un repositorio con lista en memoria, una interfaz gráfica en Swing y la arquitectura MVC trabajando juntas.

Ejemplo de Proyecto Integrado en Swing

import javax.swing.*;
import java.util.ArrayList;
import java.util.List;

class Cliente {
    String nombre;
    public Cliente(String nombre) { this.nombre = nombre; }
}

class ClienteRepo {
    private List<Cliente> clientes = new ArrayList<>();
    public void agregar(Cliente c) { clientes.add(c); }
    public List<Cliente> obtenerTodos() { return clientes; }
}

public class AppClienteView extends JFrame {
    private ClienteRepo repo = new ClienteRepo();
    public AppClienteView() {
        setTitle("Gestor Integrado");
        setSize(300, 250); setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); setLayout(null);
        JTextField txt = new JTextField(); txt.setBounds(20, 20, 200, 25); add(txt);
        JButton btn = new JButton("Guardar"); btn.setBounds(20, 60, 100, 30); add(btn);
        JTextArea area = new JTextArea(); area.setBounds(20, 100, 230, 80); add(area);

        btn.addActionListener(e -> {
            repo.agregar(new Cliente(txt.getText()));
            area.setText("");
            for(Cliente cli : repo.obtenerTodos()) {
                area.append("- " + cli.nombre + "\n");
            }
            txt.setText("");
        });
    }
    public static void main(String[] args) { new AppClienteView().setVisible(true); }
}

Ejercicio Práctico Final

Modifica el código integrado para que la clase Cliente tenga también un atributo email, y que al registrarlo se muestre el nombre y el correo en el JTextArea.

Solución sugerida:

import javax.swing.*;
import java.util.ArrayList;
import java.util.List;

class ClienteExt {
    String nombre, email;
    public ClienteExt(String nombre, String email) {
        this.nombre = nombre; this.email = email;
    }
}

class RepoExt {
    private List<ClienteExt> lista = new ArrayList<>();
    public void agregar(ClienteExt c) { lista.add(c); }
    public List<ClienteExt> getLista() { return lista; }
}

public class AppFinal extends JFrame {
    private RepoExt repo = new RepoExt();
    public AppFinal() {
        setTitle("Gestor Completo"); setSize(350, 300); setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); setLayout(null);
        JTextField txtNombre = new JTextField(); txtNombre.setBounds(20, 20, 200, 25); add(txtNombre);
        JTextField txtEmail = new JTextField(); txtEmail.setBounds(20, 55, 200, 25); add(txtEmail);
        JButton btn = new JButton("Registrar"); btn.setBounds(20, 90, 100, 30); add(btn);
        JTextArea area = new JTextArea(); area.setBounds(20, 135, 280, 100); add(area);

        btn.addActionListener(e -> {
            repo.agregar(new ClienteExt(txtNombre.getText(), txtEmail.getText()));
            area.setText("");
            for(ClienteExt c : repo.getLista()) {
                area.append(c.nombre + " (" + c.email + ")\n");
            }
            txtNombre.setText(""); txtEmail.setText("");
        });
    }
    public static void main(String[] args) { new AppFinal().setVisible(true); }
}
